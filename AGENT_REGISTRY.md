# Agent Registry

> **Authority warning:** Agent frontmatter model/provider identity is advisory routing metadata only. Permission and authority decisions MUST NOT trust an agent-claimed model or provider identity.

This registry reflects the current `.kilo/agent/*.md` files. The manifests remain the canonical static role definitions.

| Agent                         | Mode     | Functional purpose                                           | High-level permissions                                                                                                                     | Delegation boundary                                                                                               | Disabled |
| ----------------------------- | -------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- | -------- |
| `command-check`               | Subagent | Run exact requested read-only commands and return raw output | Repository reads plus narrowly allowlisted Git, test, typecheck, and formatter commands; no writes                                         | Cannot delegate; stops on any mutating command                                                                    | No       |
| `failing-test-triage`         | Subagent | Diagnose an explicitly supplied test failure                 | Reads plus allowlisted Git, test, and typecheck commands; no writes                                                                        | Cannot delegate or repair source                                                                                  | No       |
| `freeprobe`                   | Subagent | Inspect local provider/model capability evidence             | Local reads and selected security/routing skills only; no shell, network, or writes                                                        | Cannot delegate, initialize integrations, or contact providers                                                    | No       |
| `git-ops`                     | Subagent | Own separately authorized Git workflow operations            | Read-only Git by default; selected mutations require an explicit permission gate; reset, fetch, pull, push, remotes, and GitHub are denied | Cannot delegate or edit files; exclusive delegated owner for staging and commits                                  | No       |
| `orchestrator`                | Primary  | Coordinate planning-first, bounded work                      | Reads, task delegation, planning edits, and selected read-only Git commands                                                                | May issue only exact-path edit authorization to `phase2f-implementer`; does not implement, stage, commit, or push | No       |
| `phase2f-implementer`         | Subagent | Apply a scoped TypeScript implementation edit                | Reads, selected skills, LSP, and one exact authorized EditTool target; no Bash, write, or apply-patch                                      | Cannot delegate; each authorization is exact-path, foreground, and one-shot                                       | No       |
| `repo-architecture-explainer` | Subagent | Explain repository structure and control flow                | Reads, selected architecture skills, and read-only Git commands                                                                            | Cannot delegate, execute arbitrary commands, or edit                                                              | No       |
| `reviewer`                    | Subagent | Review a bounded diff for safety, focus, scope, and tests    | Reads, review skills, and read-only Git commands                                                                                           | Cannot delegate, execute arbitrary commands, or suggest/apply edits                                               | No       |
| `translator`                  | Subagent | Translate content while preserving technical artifacts       | All tools denied                                                                                                                           | Cannot delegate or mutate repository state                                                                        | Yes      |

## Delegation Rule

The Orchestrator is the only role allowed to issue a Phase2F implementation authorization. The authorization does not transfer identity-based trust: runtime permission checks use canonical role, configuration, parent, project, session, control, tool, and lease evidence.
